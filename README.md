# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改某一步后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 安全结论按前置依赖重算：材料、用量、危险项等内容字段变更后，本步骤及传递依赖它的已确认步骤立即退回待复核，并列出变动字段；仅改名称或预计时间时下游保持有效。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- 按存在危险项的步骤累计危险品用量（液体 / 固体分类换算），触到台面容量上限时拒绝冻结并指出超限步骤。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认且安全信息完整后冻结版本；冻结后内容保持原样，只能从该版本创建修订稿。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化，并列出两个版本各自的冻结拦截原因。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## 规则校验

```bash
npm run verify
```

对依赖失效重算、台面容量累计与冻结拦截规则执行离线断言（`scripts/verify-safety.ts`）。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
